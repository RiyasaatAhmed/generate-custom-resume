# Cover letter

Read [the shared cover-letter guide](../generate-custom-resume/references/cover-letter.md).
Use the supplied resume, posting, company research, and candidate voice. If a necessary
fact is missing, ask a targeted question or omit the unsupported claim. Do not invent
metrics, motivation, tradeoffs, referrals, or company details.

For letter-only requests, do not force the full resume workflow or create application
records unless needed. Deliver the requested draft/revision. When invoked from the
application command, use its existing evidence and output folder.

Retain attribution: adapted from Claude Office Skills Contributors; the original MIT
license is in [LICENSE](LICENSE). The local shared reference is the maintained writing
policy, replacing unsupported statistics and stale workflow/tool assumptions.
